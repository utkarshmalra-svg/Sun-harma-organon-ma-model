# Sun Pharma – Organon M&A Model

## Overview

This project presents a financial M&A model analyzing the proposed acquisition of Organon by Sun Pharma.

The model evaluates the transaction from the perspective of purchase price, financing structure, synergies, transaction costs, pro-forma earnings, and accretion/dilution.

The analysis was developed using Microsoft Excel and is presented through a structured M&A transaction model.

---

## Transaction Overview

**Acquirer:** Sun Pharma  
**Target:** Organon Co.  
**Transaction Type:** 100% Cash Acquisition  
**Analysis Date:** 26-Apr-2026

The model evaluates the financial impact of the acquisition on Sun Pharma's earnings.

---

## Model Components

The M&A model includes:

1. Financial Inputs
2. Transaction Assumptions
3. Purchase Price & Financing
4. Pro-Forma Net Income
5. Revenue Synergies
6. Pro-Forma Cost of Debt
7. Transaction Fee Estimation
8. Accretion & Dilution Analysis

### Financing & Cost of Debt

The model incorporates:

- Existing Sun Pharma debt
- Existing Organon debt
- New acquisition-related debt
- Weighted cost of debt

The calculated pro-forma cost of debt is approximately **7.41%**.

### Transaction Fees

Estimated transaction fees:

**₹549.04 Cr**

### Pro-Forma Earnings

The model estimates:

- Acquirer Net Income: ₹11,509 Cr

### Accretion / Dilution

The model calculates:

- Standalone EPS: ₹47.954
- Pro-Forma EPS: ₹52.553

The model therefore shows positive EPS accretion under the stated assumptions.

## Key Assumptions

The model is based on several transaction assumptions, including:

- 103% target premium
- 100% cash consideration
- Revenue synergy ramp-up
- Transaction fees
- Financing costs
- Tax assumptions
- Pro-forma interest expense
- No new shares issued

These assumptions are model inputs and should not be interpreted as actual transaction terms unless independently verified.
